# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| 0.1.x   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public issue.
2. Email **mathias@paulenko.dev** with a description of the vulnerability.
3. Include reproduction steps and potential impact if possible.

You will receive a response within 48 hours. If the vulnerability is confirmed,
a fix will be released as soon as possible and you will be credited (unless you
prefer to remain anonymous).
